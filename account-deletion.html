계정 및 데이터 삭제 안내

문서 버전 1.0 · 작성일 2026-07-14 · 개정일 2026-10-08 · 시행일 2026-10-08

이 페이지는 Family Sync(너와나 캘린더, 패키지명 com.familysync.family_sync) 이용자가 계정과 관련 데이터의 삭제를 요청하는 방법을 안내합니다. Google Play "데이터 삭제" 링크용 공식 안내 페이지입니다.

1. 삭제 요청 방법

방법 A. 앱 안에서 요청

  1. 앱 실행 → 하단 설정 탭
  2. 회원 탈퇴 선택
  3. 안내 확인 후 탈퇴 진행

요청 즉시 모든 기기에서 로그아웃되고 계정 접근이 중지됩니다. 요청일로부터 30일이 지나면 서버 작업이 계정과 개인 데이터를 자동으로 완전 삭제합니다.

방법 A-2. 보호자가 관리형 아이 계정 즉시 제거

  1. 보호자 계정으로 앱 실행 → 설정 > 연결 관리 > 아이 계정 관리
  2. 제거할 아이의 계정 제거 선택
  3. 영구 삭제 안내 확인 후 계정 제거 선택

관리형 아이 계정은 확인 즉시 로그아웃되고 계정·프로필·가족 연결·연결 코드·기기 기록이 영구 삭제됩니다. 이 삭제에는 30일 철회 기간이 적용되지 않으며 복구할 수 없습니다.

방법 B. 이메일로 요청

  • 수신처: jjanghyoson@gmail.com
  • 제목 예시: "계정 삭제 요청"
  • 본문에 적어 주세요: 앱에서 사용하는 닉네임, (이메일 가입자의 경우) 가입 이메일 주소
  • 관리형 아이 계정 삭제·법정대리인 동의 철회 요청: 보호자 가입 이메일, 가족 이름, 아이 닉네임을 적어 주세요. 보호자 권한 확인 후 처리합니다.

앱을 이미 삭제했더라도 이메일로 삭제를 요청할 수 있습니다.

2. 삭제 요청 시 삭제되는 데이터

  • 계정 및 프로필 정보 (닉네임, 프로필 사진, 이모지, 전화번호, 이메일, 생년월일, 성별 등 선택 입력 항목, 기분 상태)
  • 가족 그룹 참여 정보 (구성원 자격, 역할)
  • 본인이 만든 초대 코드와 그 사용 이력
  • 본인 앞으로 쌓인 알림 내역
  • 로그인 연결 정보 (이메일/구글/카카오/Apple 연결)
  • 관리형 아이 계정인 경우 내부 로그인 식별자, 보호자 동의 기록, 연결 코드·기기 접속 기록
  • "나만 보기"로 등록한 구독 정보와 수입·지출 항목 (본인에게만 보이던 기록이므로 계정과 함께 삭제)
  • 본인이 남긴 일상 메모와 기분 한 줄
  • 본인이 붙인 달력 날짜 스티커
  • 오류 기록에 남아 있던 계정 식별자 (기록 자체는 수집일로부터 90일 후 삭제)

기기에만 저장된 앱 설정, 홈 화면 위젯 저장본은 앱을 삭제하면 함께 제거됩니다. 외부로 공유한 백업 JSON과 이미지는 사용자가 직접 삭제해야 합니다.

3. 삭제되지 않거나 남을 수 있는 데이터

  • 캘린더에서 함께 쓰던 일정·할 일·체크리스트·버킷리스트: 다른 멤버가 계속 사용하는 공유 콘텐츠는 캘린더에 남습니다. 남는 데이터에서 탈퇴자의 프로필 연결은 해제됩니다. 본인이 작성한 일정을 함께 지우고 싶다면 탈퇴 전에 앱에서 직접 삭제해 주세요(아래 4절 참고).
  • 멤버가 함께 보던 구독 정보: 남은 멤버가 계속 결제할 수 있으므로 캘린더에 남고, 등록자 연결만 해제됩니다. 함께 지우려면 탈퇴 전에 앱에서 직접 삭제해 주세요.
  • 멤버가 함께 보던 수입·지출·고정지출 기록: 남은 멤버의 가계 집계가 어긋나지 않도록 캘린더에 남고, 등록자 연결만 해제됩니다. 함께 지우려면 탈퇴 전에 앱에서 직접 삭제해 주세요. ("나만 보기"로 등록한 항목은 위 2절에 따라 계정과 함께 삭제됩니다.)
  • 일정 활동 기록: 남은 멤버가 "누가 무엇을 바꿨는지" 확인하기 위한 기록이라 캘린더에 남을 수 있으며, 탈퇴자의 계정 연결은 해제됩니다.
  • 일정 댓글: 다른 멤버가 나눈 대화의 맥락이 끊기지 않도록 남을 수 있고 작성자 연결이 해제됩니다. 함께 지우려면 탈퇴 전에 직접 삭제해 주세요.
  • 법령상 보관 의무가 있는 기록: 해당 법령이 정한 기간 동안 분리 보관 후 파기합니다.
  • 서버 백업본: 운영 안정성을 위한 백업에 한시적으로 남을 수 있으며, 백업 주기 경과 후 순차 삭제됩니다.

4. 계정을 유지한 채 데이터만 삭제하기

계정을 지우지 않고도, 앱 안에서 개별 데이터를 직접 삭제할 수 있습니다. 삭제하면 서버에서도 함께 지워집니다.

지우려는 것앱에서의 경로
일정일정을 눌러 열고 삭제 → 확인. 반복 일정은 "이 날짜만" 또는 "모든 반복" 중에서 고를 수 있습니다
할 일 및 구매 항목할 일 탭에서 항목을 눌러 삭제 → 확인
구독 기록설정 > 구독 관리에서 항목을 열고 삭제 → 확인
수입·지출·고정지출 기록할 일 탭의 수입지출관리에서 항목을 열고 삭제 → 확인
달력 날짜 스티커캘린더에서 해당 날짜를 열고 붙여 둔 스티커를 다시 눌러 해제
일정 댓글일정을 열고 내가 쓴 댓글의 삭제
프로필 사진설정 > 내 프로필에서 사진 대신 이모지를 고르면 사진이 해제되고 서버에서도 삭제됩니다
전화번호·생년월일·성별 등 선택 입력 항목설정 > 내 프로필에서 내용을 비우고 저장
기분 한 줄 · 오늘 메모캘린더 탭의 내 카드에서 내용을 비우고 저장
초대 코드와 사용 이력설정 > 연결 관리에서 해당 초대의 삭제
아이 계정의 연결 기기 기록설정 > 연결 관리 > 아이 계정 관리에서 기기의 연결 해제
기기에 저장된 최근 입력 목록일정 입력 화면의 전체 삭제 (등록된 일정은 그대로 두고 입력 목록만 비웁니다)

앱에서 직접 지우기 어려운 경우에는 jjanghyoson@gmail.com 으로 요청해 주세요. 어떤 데이터를 지우고 싶은지 적어 주시면 본인 확인 후 처리합니다. 이 경우 계정은 그대로 유지됩니다.

여러 멤버가 함께 쓰는 캘린더의 일정·할 일·구독은 누가 만들었든 멤버라면 삭제할 수 있습니다. 다만 다른 멤버도 함께 보던 내용이므로, 지우기 전에 상의해 주세요. (일정 수정 권한은 설정 > 일반 설정에서 조정할 수 있습니다.)

5. 처리 기간

  • 삭제 요청일로부터 30일의 철회 기간이 끝난 뒤 자동 삭제합니다. 예약 작업 주기에 따라 최대 1시간이 추가될 수 있습니다.
  • 30일 안에 같은 계정으로 다시 로그인하면 삭제 요청이 자동 철회됩니다.
  • 보호자가 앱에서 관리형 아이의 계정 제거를 확정한 경우에는 즉시 영구 삭제되며 30일 철회 기간이 적용되지 않습니다.

6. 본인 확인 방법

  • 앱 내 요청: 로그인된 계정 기준으로 처리되므로 별도 확인이 없습니다.
  • 이메일 요청: 계정을 특정하기 위해 닉네임·가입 이메일 등 최소한의 정보를 확인하며, 필요 시 가입 이메일 주소로의 회신 등으로 본인 여부를 확인합니다.
  • 관리형 아이 계정 요청: 요청자의 보호자 계정과 해당 가족의 보호자 역할을 확인합니다.

7. 삭제 철회

  • 삭제가 완료되기 전에는 같은 계정으로 다시 로그인하거나 문의처로 연락하여 철회할 수 있습니다.
  • 완전 삭제 후에는 데이터를 복구할 수 없습니다. 관리형 아이 계정의 연결 코드와 기기 접속도 복구되지 않습니다.
